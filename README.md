# end_to_end_drug_discovery_project_-python-
Bioinformatics end to end project for drug discovery 
1) collect data directly from the bioactivity database Chembl and pre-processing 
2) computing molecular descriptors (lipinski) and perform exploratory data analysis on them --> likelihood to be a drug-like molecule
3) calculate molecular descriptors and prepearing the dataset --> use of Acetylcholinesterase because it is a larger dataset
4) regression model building (ML) --> prediction model
5) compare models (machine learning algorithms)
